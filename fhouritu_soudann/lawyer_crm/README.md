# 弁護士事務所CRM

PHP + MySQL + Bootstrap 5 で構築した弁護士事務所向けCRMシステムです。

## 機能一覧

| 機能 | 説明 |
|---|---|
| ダッシュボード | 今週の期日・受任中案件・未収金サマリー |
| 依頼人台帳 | 氏名・連絡先・住所・メモ管理、案件紐付け |
| 案件管理 | 種別・着手日・状態・担当弁護士・裁判所管理 |
| 進捗タイムライン | 活動記録（面談・書類作成・裁判・交渉等） |
| 期日リマインド | 裁判期日・提出期限の一覧・超過アラート |
| 着手金・報酬管理 | 請求・入金管理、未収金集計 |
| 書類管理 | ファイルアップロード（PDF・Word・画像対応）|
| ログイン認証 | セッションベース認証 |

## ディレクトリ構成

```
01_lawyer_crm/
├── config.php           # DB設定・共通関数
├── login.php            # ログイン画面
├── logout.php           # ログアウト
├── setup.php            # 初期セットアップ（管理者作成）
├── index.php            # ダッシュボード
├── clients.php          # 依頼人一覧
├── client_detail.php    # 依頼人詳細
├── client_form.php      # 依頼人新規登録・編集
├── cases.php            # 案件一覧
├── case_detail.php      # 案件詳細（タイムライン・期日・請求）
├── case_form.php        # 案件新規登録・編集
├── deadlines.php        # 期日リマインド一覧
├── billing.php          # 着手金・報酬管理
├── documents.php        # 書類管理・アップロード
├── includes/
│   ├── header.php       # サイドバー・ナビゲーション
│   └── footer.php       # フッター・JS読み込み
├── uploads/             # アップロードされた書類の保存先
├── schema.sql           # データベーススキーマ
└── seed.sql             # サンプルデータ（20件）
```

## セットアップ手順

### 1. データベース作成

```bash
mysql -u root -p < schema.sql
mysql -u root -p < seed.sql
```

### 2. DB設定を変更

`config.php` を編集してDBの接続情報を設定：

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'lawyer_crm');
define('DB_USER', 'root');
define('DB_PASS', 'your_password');
```

### 3. uploadsディレクトリの権限設定

```bash
chmod 755 uploads/
# Apacheの場合
chown www-data:www-data uploads/
```

### 4. 管理者アカウントの作成

ブラウザで `setup.php` を開き、管理者アカウントを作成します。

**セットアップ後は `setup.php` を削除してください。**

```bash
rm setup.php
```

### 5. ログイン

`login.php` にアクセスして、setup.phpで作成したユーザーでログインしてください。

## サンプルデータ

`seed.sql` には以下のサンプルデータが含まれています：

- **依頼人**: 20名（架空）
- **案件**: 20件（離婚・相続・交通事故・労働・刑事・債務整理・不動産・建設・家族親権）
- **活動記録**: 約50件（各案件の進捗タイムライン）
- **期日**: 約30件（今週・近日中のものを含む）
- **請求記録**: 約25件（着手金・成功報酬・実費）

## 案件種別

| 種別 | 例 |
|---|---|
| 離婚 | 離婚調停・審判・財産分与・DV |
| 相続 | 遺産分割調停・遺言無効確認 |
| 刑事 | 傷害・横領 刑事弁護 |
| 民事 | 売買代金・請負代金請求 |
| 労働 | 不当解雇・残業代・ハラスメント |
| 交通事故 | 損害賠償・後遺障害 |
| 債務整理 | 個人再生・自己破産 |
| 不動産 | 敷金返還・瑕疵担保責任 |
| 建設・請負 | 工事欠陥・代金請求 |
| 家族・親権 | 養育費・親権変更 |

## 動作要件

- PHP 8.1以上
- MySQL 5.7以上 / MariaDB 10.3以上
- Webサーバー（Apache / Nginx）
- Bootstrap 5.3（CDN経由）

## セキュリティに関する注意

- 本システムはデモ用です。本番運用前にセキュリティ強化を行ってください
- uploadsディレクトリは直接アクセスできないよう `.htaccess` で保護することを推奨します
- セッション設定・CSRF対策・SQLインジェクション対策を本番前に見直してください
- 個人情報保護法・弁護士秘密保持義務の観点から、適切なアクセス制御・暗号化・バックアップ体制を整備してください
